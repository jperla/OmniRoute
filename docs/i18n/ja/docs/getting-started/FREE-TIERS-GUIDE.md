> **TL;DR** : 対象となる独自のプロバイダー アカウントを持ち込んでください。 OmniRoute設定した接続を結合します。宣伝された総トークン予算は発行されません。無料アクセスには、サインアップ、 APIキー、承認、または支払い方法が必要な場合があります。プロバイダーの制限、プライバシー ポリシー、および規約は引き続き適用されます。

---

## 無料枠とは何ですか?

多くのAIプロバイダーは、何らかの形式の**無料アクセス**。プロバイダーによっては、これは、認証なしのエンドポイント、定期的なクォータ、レート制限された上限なしのアクセス、サインアップの許可、手動承認、または一時的なプロモーションを意味する場合があります。一部のオプションでは、アカウント、 APIキー、クレジット カード、 KYC、またはプロバイダー固有の規約への同意が必要です。

OmniRoute**骨材**構成された接続を 1 つのエンドポイントにまとめます。アカウントが必要なプロバイダーごとに個別にサインアップすることになります。これらのアカウントを接続し、 `model: "auto"`を使用して対象となるターゲット間をルーティングします。新規インストールには、適格なキーレス ターゲットを含めることはできません。 OmniRoute単独でインストールしても、チャットの応答が成功することは保証されません。

## 無料枠を積み重ねる方法

OmniRouteの魔法は**無料枠の積み重ね**。 1 つのプロバイダーに依存するのではなく、複数の無料プロバイダーに接続し、 OmniRouteリクエストごとに最適なプロバイダーを自動的に選択できるようにします。

### 例: より広範な無料利用枠の範囲

複数のプロバイダーを接続して、単一のクォータへの依存を減らします。

1. **Gemini** —の定期的な API キー割り当て
2. **Groq** —の定期的な API キー割り当て
3. **受粉**—キーレス、レート制限付きアクセス
4. **LongCat** —ワンタイム サインアップ許可 ( KYCが必要)

次に、 `model: "auto"`使用すると、 OmniRoute次のようになります。

- 最初に最高ランクの適格な接続を試してください
- クォータまたはヘルスチェックが→失敗した場合は、次に構成されたプロバイダーを試してください
- キーレスプロバイダーが利用できない場合、 →残りのターゲットを続行します。
- 適格な接続が成功しない場合、 →エラーを返します。サインアップ クレジットは、有効かつ利用可能な場合にのみ使用できます。

**結果**: 自動フォールバック—によるより広い無料枠の適用範囲は、無制限の容量を保証するものではありません。

## 無料プロバイダーに接続する方法

### ステップ 1: ダッシュボードを開く

ブラウザで`http://localhost:20128`にアクセスします。

### ステップ 2: プロバイダーに移動する

クリック**プロバイダー**サイドバーにあります。

### ステップ 3: 「プロバイダーの追加」をクリックします

をクリックします。**+プロバイダーの追加**ボタン。

### ステップ 4: 無料のプロバイダーを選択する

カタログを参照して、各プロバイダーの現在の`hasFree`、認証、クォータ、プライバシー、およびToSメタデータを検査します。プロバイダー カードと[無料利用枠リファレンスは](../reference/FREE_TIERS.md)、定期プール、 uncapped/keylessアクセス、サインアップ クレジット、廃止されたエントリ、および高リスクのソースを区別します。

### ステップ 5: 「接続」をクリックします

`NOAUTH`プロバイダーの場合、 OmniRouteアップストリームの資格情報を要求しません。これは、アップストリームがサードパーティのクライアントを受け入れること、または使用可能な容量があることを保証するものではありません。 OAuthと API キープロバイダーは、文書化されたアカウント フローを通じて接続する必要があります。クライアントは、で作成されたOmniRoute APIキーを引き続き使用しています。**ダッシュボード→ APIキー**ルーター認証が有効な場合 (作成時に 1 回のみ表示されます)。

### ステップ 6: 繰り返します

利用条件とプライバシー モデルがユースケースに適合する複数のプロバイダーを接続します。

## dsh「当社の無料モデル」から

dsh エージェント ホストの[dsh-our-free-model](https://github.com/Ebony-Vinyl/dsh-our-free-model)プラグインは 2 つのアップストリームに到達します。 OmniRouteにはすでにそれぞれのプロバイダーがありますが、 OmniRoute内のフリー パスはそのうちの 1 つだけです。

| プラグインレーン | 上流                                           | OmniRouteプロバイダー     | OmniRouteでは無料ですか？ | 接続方法                                                                            |
| ---------------- | ---------------------------------------------- | ------------------------- | ------------------------- | ----------------------------------------------------------------------------------- |
| キロチャンネル   | キロAIゲートウェイ (`api.kilo.ai/api/gateway`) | `kilo-gateway` (別名`kg`) | はい                      | APIキーはオプション: ゲートウェイの空きプールを使用する場合は空のままにしておきます |
| フリーレーン     | OpenCode禅 (`opencode.ai`)                     | `opencode-zen`            | いいえ                    | [opencode.ai/zen](https://opencode.ai/zen)からの独自のOpenCode APIキー              |

**キロ。**フリー プールを`kilo-gateway/<model>`または`kg/<model>`として呼び出します。たとえば、 `kg/kilo-auto/free` (Kilo の無料自動ルーター) またはゲートウェイの`:free`モデルの 1 つです。フリーセットは回転します。 `kilo-gateway` 、 OmniRouteの組み込みリストにないモデル ID をパススルーするため、ゲートウェイが現在リストしているモデルをカタログに含める前に呼び出すことができます。 Kilo の無料モデル カードによると、プロンプトは上流のプロバイダーによって記録され、サービスの向上に使用される可能性があるため、機密データは送信しないでください。

**OpenCode。**プラグインの無料レーンはOpenCodeのキーフリー オファーです。 OmniRoute 、そのオファーを無料アクセスとして提供しません。

- OmniRouteのキーレスOpenCodeプロバイダーは、 OpenCodeのオペレーターの要求により削除されました ( [「削除されたプロバイダー](../reference/REMOVED_PROVIDERS.md)」を参照)。
- OpenCodeの[エンドポイント ドキュメントでは、](https://opencode.ai/v2/docs/console/models/#endpoints)その無料チャット オファーがOpenCode独自のクライアントに関連付けられているため、 OmniRouteそれらを無料としてカウントしたり、バッジを付けたりしません。

プラグインが表示するモデル ID `deepseek-v4.1-flash-free`、 `mimo-v2.6-flash-free` 、 `nemotron-3.5-lightning-free`など) は、 `opencode-zen`カタログにあります。 OpenCodeアカウントの条件に従って使用するには、 `opencode-zen`独自のOpenCodeキーに接続します。

**プラグインのローカルポート。**このプラグインは、ローカルの OpenAI 互換ポート (デフォルト`18899`) でモデルを公開できます。このようなエンドポイントは[カスタム OpenAI 互換プロバイダー](../guides/USER_GUIDE.md#custom-openai-compatible-providers)として追加できますが、 OmniRouteプラグインのインストール、起動、更新を行わず、プラグインが各リクエストをどのアップストリームで処理するかを決定します。上記のOpenCode制限は、どのクライアントがリクエストを送信してもOpenCodeのオファーに適用されます。

## カタログを正しく読む

- `NOAUTH` 、 OmniRouteプロバイダーの資格情報を要求しないことを意味します。稼働時間、プライバシー、無制限の容量を保証するものではありません。
- `hasFree`はディスカバリー・メタデータです。これは、定期的な割り当て、キーレス アクセス、サインアップ クレジット、承認プログラム、またはプロモーションを表すことができます。
- `recurring-uncapped` 、公開されたトークン上限が利用できないことを意味します。レートと同時実行の制限は引き続き適用されます。
- サインアップ許可が消費された後は、`one-time-initial`再発しません。
- `tos: avoid`プロバイダーは、デフォルトでは自動ルーティングから除外されます (`excludeTosAvoid`)。アカウントを接続しても、このフィルターはバイパスされません。演算子をオーバーライドする場合は、プロバイダーの規約とアカウントのリスクを確認する必要があります。
- `discontinued`とマークされたエントリは歴史的な証拠として残り、現在無料として提示してはなりません。

## OmniRoute無料枠をどのように改善するか

### 1. 自動フォールバック

1 つの無料プロバイダーがビジーまたはダウンしている場合、 OmniRoute自動的に次のプロバイダーを試行します。何もする必要はありません。

### 2. スマートルーティング

OmniRouteが選ぶのは**最高の無料プロバイダー**各リクエストは以下に基づいて行われます。

- 速度—現在最も速いプロバイダはどれですか?
- 品質—このタスクに最適なプロバイダーはどれですか?
- 容量—どのプロバイダーに割り当てが残っていますか?

### 3. トークンの節約

OmniRouteの圧縮パイプラインは、対象となるプロンプトおよびツール出力トークンを減らすことができます。実際の節約額は、コンテンツ、選択したエンジン、プロバイダーのアカウンティング、忠実度の設定によって異なります。圧縮によって、すべてのプロバイダー クォータが固定量で乗算されるわけではありません。

### 4. マルチアカウントのサポート

プロバイダーの規約で複数のアカウントまたは資格情報が許可されている場合、 OmniRoute各接続を個別のルーティング候補として扱うことができます。プロバイダーの割り当てやアクセス ポリシーを回避するために追加のアカウントを作成しないでください。

## 無料枠の計算

プールの重複排除されたライブ カタログでは現在、次のレポートがレポートされます。

| メトリック                       |             現在の監査値 | 解釈                                                                          |
| -------------------------------- | -----------------------: | ----------------------------------------------------------------------------- |
| 定期的な定量化された助成金       | **~ 1.62B tokens/month** | 共有プールは 1 回カウントされます。上限のないプロバイダーを合計から除外します |
| 最初の月はサインアップ補助金付き |      **~ 222億トークン** | 定期的な合計と 1 回限りのクレジットと定期的なクレジット                       |

これらは、対象となる個別のアカウントにわたるカタログ全体の推定値であり、 OmniRouteによって提供される許容量や新規インストールの予測ではありません。使用可能な容量は、接続するプロバイダーとその現在の状況によって異なります。値は`open-sse/config/freeModelCatalog.ts`から計算されます。プールの重複排除、 ToSフラグ、廃止されたエントリ、およびサインアップ クレジット方法については、「[無料利用枠リファレンス」を](../reference/FREE_TIERS.md)参照してください。

## よくある質問

### 「これ本当に無料なの？」

カタログにはプロバイダーが公開した条件とプロジェクト調査が記録されていますが、オファーは変更される可能性があります。使用する前に、プロバイダーの現在の価格、割り当て、プライバシー ポリシー、資格を確認してください。

### 「無料枠がなくなってしまいますか？」

すべてのプロバイダーは、レート制限、モデルの変更、アクセスの一時停止、またはオフラインにすることができます。複数の接続によりフォールバック カバレッジが向上しますが、利用可能な空きルートが保証されるわけではありません。

### 「本番環境に無料のプロバイダーを使用できますか?」

プロバイダーのSLA、データ処理、制限、および条件が運用要件を満たしている場合のみ。重要なワークロードは、契約上適切なフォールバックを監視する必要があります。

### 「何が問題ですか？」

トレードオフには、厳格な制限、待機リスト、 KYC、クレジット カード検証、プロンプトに関するトレーニング、プライバシーの弱さ、 SLAなし、モデルのチャーン、地理的制限、支払い超過、またはアカウント ポリシーのリスクが含まれる場合があります。 OmniRoute利用可能なメタデータを表示します。何を有効にするかを選択します。

### 「無料割り当てを増やすにはどうすればよいですか?」

1. より多くの無料プロバイダーに接続する
2. 適切な圧縮エンジンを有効にして、ワークロードの節約を測定します。
3. `auto/cheap`を使用してfree/cheapプロバイダーに優先順位を付ける
4. プロバイダー規約に違反することなく、許可されたプロバイダーまたは資格情報を追加します。

### 「無料のプロバイダーは品質が悪いのでしょうか？」

必ずしもそうとは限りません。一部のプロバイダーは、有料ルートを通じて利用可能な同じモデル ファミリを公開していますが、制限、遅延、プライバシー、信頼性、モデル バージョンが異なる場合があります。無料プロバイダー ランキング ページを品質のシグナルとして使用し、提供される実際のモデルを確認します。
